# sinaheidaripour

Personal website — static HTML/CSS/JS, hosted on GitHub Pages (no build step, no backend).

## Deploy
1. Merge this branch into `main`.
2. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`**.
3. Site goes live at `https://sinahdp.github.io/sinaheidaripour/`
   (name the repo `sinahdp.github.io` to serve it at `https://sinahdp.github.io/`).
